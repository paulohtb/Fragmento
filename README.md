Minecraft Mod: Fragmento

Fragmento is a custom Minecraft modification built with Java using the Neo-Forge library. This mod adds new gameplay mechanics, items, and features to enhance the Minecraft experience.

Technical Details
- Language: Java
- Modding Library: Neo-Forge
- Compatible Minecraft Version: 1.21.1
- Build Tool: Gradle / Maven (whichever applies)

Code Organization:
- src/main/java – Java source files.
- src/main/resources – Assets, textures, and JSON files.
